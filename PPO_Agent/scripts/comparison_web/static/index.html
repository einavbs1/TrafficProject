Models to Compare

Tick the trained agents you want to test. The project's champion model is ticked by default. Add another saved .zip checkpoint's full path below to test it alongside.

Baselines to Include

Plain, non-learned traffic lights to compare against, each running a fixed cycle of the given length in seconds. Tick any you want included; the trained agent's whole point is to beat these.

Seeds

A seed fixes the exact traffic (which cars, when) so every model and baseline faces the identical situation. Random: generate that many fresh, never-used seeds. Manual: type specific seed numbers to reproduce an exact past result.

Scenario

How much traffic to simulate. Low: light, sparse traffic. Medium: typical, steady traffic. High: heavy, near-saturating traffic. All: run all three in one comparison (Watch Live needs exactly one, not All).

Requires exactly 1 seed and one specific scenario (not "All"). Any number of models/baselines run one at a time, one visible window at a time. When you are ready, click Start Comparison below to run every selected model and baseline.

Results

Once a run finishes, a table appears here for each tested scenario: total waiting time per seed and an overall average for every model and baseline. The best (lowest) average in each table is highlighted, with a bar chart below it for a quick visual comparison. Lower is better.
